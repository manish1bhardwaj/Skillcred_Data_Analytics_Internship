# SkillCred Data Analytics Internship

A collection of assignments, practice workbooks, and learning materials completed as part of the **SkillCred Data Analytics Internship**. This repository documents hands-on practice with Microsoft Excel, data cleaning, data transformation, formulas, lookups, charts, and pivot tables.

## About the Repository

The repository contains Excel workbooks, CSV data, and supporting learning material covering foundational data analytics tasks. The exercises focus on organizing data, applying spreadsheet functions, summarizing information, and presenting data in a useful format.

## Topics Covered

- **Excel fundamentals:** workbook navigation and introductory exercises
- **Data cleaning and transformation:** preparing data for analysis
- **Formulas and functions:** `IF`, `COUNTIF`, `SUMIF`, and related conditional calculations
- **Lookup functions:** `VLOOKUP` and lookup practice
- **Date and text functions:** working with dates and text values
- **Conditional formatting:** highlighting data based on rules
- **Sorting and filtering:** organizing records for easier analysis
- **Pivot tables:** summarizing and exploring datasets
- **Charts and graphs:** presenting information visually
- **Supply chain domain knowledge:** introductory reference material
- **Assessments and project solutions:** practice and assessment files

## Tools and File Formats

- **Microsoft Excel:** spreadsheet formulas, cleaning, analysis, pivot tables, and charts
- **CSV:** tabular data for assessment or analysis
- **PDF:** reference and domain-learning material
- **XLSX / XLSM:** Excel workbooks, including macro-enabled workbooks (`.xlsm`)

## How to Use This Repository

1. Clone or download the repository from GitHub.
2. Open the relevant workbook in Microsoft Excel or a compatible spreadsheet application.
3. Review the worksheets, formulas, and outputs.
4. For assessment or project files, compare the working sheets with the provided solution where applicable.
5. Use the exercises for learning and practice; verify formulas and results before reusing them.

## Learning Outcomes

Through these exercises, the repository demonstrates practice in:

- Preparing and cleaning raw data
- Applying common Excel formulas and lookup functions
- Summarizing data with pivot tables
- Creating charts to communicate findings
- Working with structured datasets and assessment files
- Building a foundation for data analytics workflows
